# Content translation snapshots

Generated by `npm run translate:content` (see `scripts/translate.mts`).
Each `{locale}.json` maps `entityType → entityId → field → translatedText`
for the catalog content (tools, news, blog, categories, tags, deep dives).

These files are **optional**: the site falls back to English when a locale
snapshot is missing, and reads live translations from Supabase
(`content_translations`) when that is configured. Committing them (the
`.github/workflows/translate.yml` action does this daily) makes every locale
render translated content even on Vercel Hobby with no database.
